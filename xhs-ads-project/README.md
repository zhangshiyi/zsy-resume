# 小红书投放数据看板（脱敏演示版）

分品类投放监控看板：某户外品牌的小红书「标准投」广告数据，覆盖品类A / 品类B / 品类C 三条品类线的日报与区间复盘。本目录为**简历作品集版本**，原始数据已脱敏。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 核心看板，单文件自包含（数据已内嵌），双击浏览器打开即可，无需服务器 |
| `index.backup-before-ai-slot.html` | 接入 AI 插槽前的备份版本 |

## 功能

- **今日 / 本月累计**双视图，日期区间自由筛选（5/21 起任意起止组合，528 个区间预计算直接取数）
- 全部 / 品类A / 品类B / 品类C 分品类筛选，联动所有数据板块
- 每日投放趋势图、分品类指标卡、达人 / 人群 / 词包 / 方向 / 渠道维度拆解
- **笔记四象限图**：组件成本 × CPE 散点（按区间中位数划线），每象限 ≥3 篇，双优区 / 复盘区一目了然
- **AI 观察手记**：渲染流水线末端的 LLM 插槽工位，自动生成当前视图的数据解读（详见下文）

## AI 洞察插槽（LLM Workflow）

看板在渲染流水线末端挂载了一个 **LLM 插槽工位**：控制流完全归页面代码所有，模型只在固定位置做「指标 JSON → 解读文本」的单次转换。

- **接口约定**：输入 = 代码侧采集的指标 JSON（当前视图/品类、消耗、CPC/CPE/CPTI、环比、TOP 人群/达人/笔记）；输出 = `{text, tags[]}`，text 需通过 Schema 校验（20~600 字符）
- **三层 Provider 链**：真实 LLM → 离线演示 → 规则摘要，逐层自动降级，任何一层故障都不影响看板本体
- **默认 Provider**：离线演示版（确定性规则生成，无网络依赖），供无网环境直接演示
- **接入真实 LLM**：点击面板右上角徽标，粘贴 OpenAI 兼容配置一次即可：
  `{"url":"https://open.bigmodel.cn/api/paas/v4/chat/completions","key":"你的Key","model":"glm-4-flash"}`
  智谱开放平台 / DeepSeek 端点已验证支持浏览器直连（CORS）；**密钥仅存本机 localStorage，不写入任何文件**——index.html 单独分享出去不会带密钥；清空配置即恢复演示层
- **回退机制**：真实调用超时（12s）/ 报错 / 输出不合规时自动落到演示层；演示层再异常才回退规则摘要；同视图结果会话内缓存，避免重复调用
- **开发者接口**：`window.LLM_SLOT_CONFIG.provider = async (metrics) => ({text, tags})` 可注入自定义 Provider

## 数据范围与口径

- 区间：2026-05-21 ~ 2026-06-21（另含 6/22 单日）
- CPC = 消费 / 点击量；CPE = 消费 / 互动量；组件成本 = 消费 / 搜索组件点击量；CPTI = 消费 / 新增深度种草人群
- 基准线 = 区间内全部有效笔记的各指标中位数

## 脱敏说明

- 广告主 ID 已移除；111 位达人昵称替换为「达人01 ~ 达人111」（映射一致，同名始终同代号）
- 品类名（登山鞋/徒步鞋/跑山鞋）替换为品类A/B/C；人群、词包、内容方向、竞品（Hoka、lowa、norda、可隆、始祖鸟、昂跑、萨洛蒙、迈乐等）统一替换为「竞品A/B/C…」；笔记 ID 全部替换为等长伪 ID（一一对应）
- **数值扰动**：三条品类线的单日消耗已相互交换、日期错位，人群消耗按稳定系数重排并归一化；扰动后所有成本比率（CPC / CPE / 组件成本 / CPTI / 点击率）由扰动后的消费与计数重新推导，逻辑自洽，总量与结构均与真实业务无对应关系
- 品类合计 = 全部、汇总 = 每日之和 等内部勾稽关系已逐项校验
- 「登山鞋品类人群女性」等内部定向细节人群已删除；维度列表中消耗为 0 的条目不再展示

## 数值深度扰动

- 消耗规模：品类单日互换 + 日期错位置换 + 全局缩放（×0.68）与按日/按品类抖动，总量与明细均与真实业务无对应
- 成本比率（CPC / CPE / 组件成本 / CPTI）：由扰动后的消费与计数重新推导，逻辑自洽、量级可信
- 全部 528 个区间、每日曲线、品类合计、人群/词包/达人/方向/渠道拆解均由扰动后的日数据重建，勾稽关系（品类合计=全部、汇总=每日和、CPC=消费÷点击）逐项校验
- 页面展示数值与真实业务无任何对应关系；四象限散点位置随重采样后的比率重算

## 技术要点

- 单文件自包含：数据以 JSON 内嵌，无外部依赖、无网络请求，任何设备浏览器可直接打开
- 528 个日期区间组合全部预计算，筛选交互零延迟
- 四象限散点为手写 SVG，标签位置经渲染实测避让（零重叠、零压点）
- AI 插槽：三层 Provider 链（真实 LLM → 离线演示 → 规则摘要），Schema 校验 + 12s 超时 + 会话内缓存；密钥仅存 localStorage，分享文件零泄漏
- 响应式布局适配桌面 / 移动端，含键盘可达性与 `prefers-reduced-motion` 支持
